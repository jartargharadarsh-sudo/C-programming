# Day 06 - File Handling

**Author:** Adarsh

## Description
A program that reads and prints characters one by one from a text file using file pointers.

## Concepts Learned
- Opening and closing files with `fopen` and `fclose`
- Reading character by character using `fscanf`
- File pointers (`FILE *`)

## Key Takeaways
- Understood how C interacts with external files.
- Learned the importance of checking whether a file opened successfully.
